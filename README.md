### 📄 AI Resume Screener & Job-Matching System

**Problem:** Manually matching resumes to job descriptions is slow and inconsistent.

**What I built:**
- Built an **NLP resume-JD matching system** to extract, clean, and tokenize resume and job-description text
- Extracted skills using **spaCy NER** and keyword taxonomy; applied **TF-IDF and cosine similarity** to generate match scores
- Developed a **Flask** app displaying match percentage, matched skills, and missing skills
- Tested with a 20-resume Kaggle dataset

**Stack:** `Python` `spaCy` `scikit-learn` `Flask` `PyPDF2` `pdfplumber`

### 🌿 Plant Disease Detection System (CNN)

**Problem:** Manual plant disease diagnosis is slow and error-prone for farmers.

**What I built:**
- Trained a **transfer-learning CNN** using **MobileNetV2** on the PlantVillage dataset for multi-class plant disease detection, leveraging cloud computing for training
- Fine-tuned the classification head and evaluated validation performance using accuracy and a confusion matrix
- Deployed an interactive **Streamlit** app for image upload and real-time disease prediction

**Stack:** `Python` `TensorFlow/Keras` `MobileNetV2` `Streamlit` `Google Colab`

</td>

### 🎬 Movie Recommendation System

**Problem:** Users struggle to discover relevant movies from large catalogs.

**What I built:**
- Built a **hybrid recommender** using **TF-IDF content filtering** and **collaborative filtering with SVD** on the MovieLens 100K dataset
- Combined content and collaborative signals with weighted scoring for rank aggregation
- Developed a **Streamlit** interface returning 10 personalized movie recommendations

**Stack:** `Python` `Pandas` `scikit-learn` `Surprise` `Streamlit`
